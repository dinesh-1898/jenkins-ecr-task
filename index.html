CI/CD Flow

  1. Developer pushes code to GitHub
  2. Jenkins clones the repository
  3. Jenkins builds the Docker image
  4. Jenkins authenticates with AWS ECR
  5. Docker image is tagged
  6. Docker image is pushed to ECR
  7. Image is verified in AWS ECR
